FDR-Alpha 飛行紀錄器 — 操作說明手冊

📡 系統概述
功能定位
FDR-Alpha 是一款基於瀏覽器的 GPS 飛行紀錄工具，透過裝置內建 GNSS 感測器即時擷取飛行數據，並在任務結束後自動匯出為標準 GPX 格式檔案。
適用裝置
支援具備 GPS 功能的智慧型手機、平板電腦，或外接 GPS 模組的筆電。建議使用 iOS Safari 或 Android Chrome 瀏覽器以獲得最佳定位精度。
使用前提
首次使用時，瀏覽器會要求 位置權限，請務必允許。建議在戶外或視野開闊處操作以確保 GPS 訊號品質。

Ground Speed
GPS 地速（浬/時 KTS），由裝置 GPS 速度向量換算。
Altitude MSL
GPS 高度換算為呎（MSL），精度取決於 GPS 垂直定位能力，一般誤差 ±30 呎。
Vertical Speed
每分鐘爬升或下降速率（FPM），由前後兩點高度差與時間差計算。正值為爬升，負值為下降。
Heading
GPS 移動方位角（°），為真北航向。靜止時數值可能不穩定，飛行速度 > 5 KTS 時較為可靠。
🛰️ GPS 狀態指示
衛星數量
右上角 SAT 數字顯示估算衛星連線數量，由 GPS 精度推算：
• 精度 < 10m → 12 SAT（優良）
• 精度 10–30m → 6 SAT（良好）
• 精度 > 30m → 3 SAT（較差）
狀態指示燈
灰色：GPS 已連線，待機中
綠色閃爍：正在錄製中
低訊號警告
當估算衛星數 < 4 顆時，畫面中央顯示 WARNING: LOW GPS SIGNAL，此時數據精度下降，建議移至開闊地點後再開始錄製。
💡 室內、隧道、高樓密集區可能導致 GPS 訊號遮蔽，飛行前請確認 GPS 已鎖定。
⏺️ 錄製操作流程
1
開啟飛行紀錄器頁面，允許瀏覽器存取位置權限，等待右上角 SAT 數值穩定（建議 ≥ 6）。
2
確認 HUD 數值開始更新後，按下底部 Start Recording 按鈕開始錄製。按鈕變紅並顯示「Stop Recording」，狀態指示燈轉為綠色。
3
Mission Time 計時器開始計時，系統每次 GPS 更新時自動記錄一筆飛行數據（位置、高度、速度、航向、時間）。
4
飛行結束後，按下 Stop Recording 停止錄製，系統自動觸發 GPX 檔案下載。
5
下載的 FDR_MISSION_*.gpx 檔案可匯入 飛行分析器 進行航跡回放與數據分析。
⚠️ 自動停止機制：系統設有 5 小時自動停止保護，超時後自動觸發停止並匯出，防止因忘記停止導致裝置過熱或資料遺失。
💡 螢幕常亮（Wake Lock）
功能說明
錄製開始後，系統自動請求 Screen Wake Lock 防止螢幕熄滅，確保 GPS 持續運作不中斷。
支援條件
需使用支援 Wake Lock API 的瀏覽器（Chrome 84+、Edge 84+）。iOS Safari 目前不支援，建議手動設定螢幕常亮。
停止後釋放
按下停止錄製後，Wake Lock 自動釋放，螢幕恢復正常省電模式。
💡 iOS 使用者可在「設定 → 螢幕顯示與亮度 → 自動鎖定」中暫時關閉自動鎖定以達到同等效果。
📂 GPX 匯出格式
檔案格式
匯出為 GPX 1.1 標準格式，相容於大多數飛行分析軟體與地圖工具。
檔案命名
FDR_MISSION_[時間戳].gpx，時間戳為任務停止時的 Unix 毫秒時間。
紀錄欄位
每筆航跡點包含：
• lat / lon 緯度／經度（WGS84）
• ele 高度（公尺 MSL）
• time UTC 時間（ISO 8601）
• speed 地速（公尺/秒）
• vsi 垂直速度（呎/分）
• heading 航向（度）
💡 GPX 檔可直接匯入本平台的「飛行分析器」進行航跡回放、速度曲線與高度剖面分析。
❓ 常見問題
SAT 顯示 0
確認已允許位置權限，並在戶外等待 30–60 秒讓 GPS 暖機鎖定衛星。部分裝置在冷啟動時需要較長時間。
高度數值不準
GPS 垂直精度通常比水平精度差 2–3 倍，誤差 ±30–50 呎為正常現象。如需高精度高度資料，建議搭配氣壓高度計。
停止後無下載
若錄製時間過短（未紀錄到任何 GPS 資料點），系統不會觸發下載。建議至少錄製數秒並確認 HUD 有數值更新。
頁面切換後中斷
切換至其他 App 或分頁可能導致瀏覽器暫停 GPS 更新。錄製期間請保持此頁面在前景運作。
